Questions, answered.

Is this an official OpenAI or Discord service?

No. CodexAlert is an unofficial community project and is not affiliated with or endorsed by OpenAI or Discord.

Where does the reset signal come from?

Reset data comes from hascodexratelimitreset.today, created by @jskoiz. It is third-party data and may be delayed or inaccurate.

How often does CodexAlert check?

One shared Supabase check runs every minute for all subscribers. It does not poll once per subscriber.

What happens to my webhook URL?

It is tested, encrypted before storage, and never returned to the browser. Unsubscribing removes the stored credential.

How do I stop alerts?

Use the private unsubscribe link shown after Discord setup. Anyone with that link can remove the subscription, so keep it private.

When will Telegram and Slack be ready?

They are planned channels, but Discord is the only live delivery route today.

Still want the signal?

Discord setup takes one webhook and one test message.
