Private by design

Your webhook is a credential.
We treat it like one.

Webhook URLs are encrypted before storage, never returned to the browser, and used only to deliver the notifications you requested. The public website contains no server secrets.

  • Encrypted at rest with a server-only key
  • No email, name, Discord account, or OAuth
  • Credential material removed when you unsubscribe
  • Open source security model

The fine print

Questions, answered.

Is this an official OpenAI service?

No. This is an unofficial community project and is not affiliated with or endorsed by OpenAI or Discord.

How accurate are the reset alerts?

Alerts reflect a third-party status source and may be delayed or inaccurate. Messages intentionally say limits “appear” to have reset.

What data is stored?

An encrypted webhook URL, keyed duplicate fingerprint, hashed unsubscribe token, delivery health timestamps, and bounded operational logs. We do not ask for identity data.

Will the same reset spam my channel?

No. Each reset and subscription pair has a unique database record, and deliveries are claimed before any Discord request is made.

How do I unsubscribe?

Use the private unsubscribe link shown once after setup. The webhook credential is removed immediately when that link is used.
