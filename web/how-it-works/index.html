CodexAlert turns one community-maintained reset signal into a quiet notification route. The check is shared, the signal is deduplicated, and your webhook only hears about a new event.

The signal path

One source, one scheduled check, one delivery per reset.

1

We read the source

Supabase checks hascodexratelimitreset.today once per minute. The source is a third-party community project created by @jskoiz.

2

We lock the event

A stable reset timestamp or source event ID is stored so the same reset cannot trigger a second notification for the same subscription.

3

Your channel gets the pulse

Discord receives one concise message when a new reset is reported. Telegram and Slack routes will follow in a later release.

Webhook URLs are encrypted before storage and never returned to the browser.
