Privacy, plainly.

Effective 30 August 2026. CodexAlert delivers one useful signal without asking for an account.

Information we receive

For a Discord subscription, we receive the webhook URL you submit, a keyed duplicate fingerprint, a hashed unsubscribe token, delivery health data, and a short-lived keyed request fingerprint for abuse prevention. We do not store raw IP addresses.

How we use it

The webhook is used to send the confirmation and reset notifications you request. It is encrypted before storage and never returned to the browser.

Deletion and providers

Use your private unsubscribe link to deactivate a subscription and erase its stored webhook credential. Supabase provides database and server infrastructure; Discord receives only the messages needed for delivery. We do not sell personal data.

What we do not collect

No name, email address, Discord login, OAuth permission, or message history is required.

Third-party source

Reset data comes from hascodexratelimitreset.today, created by @jskoiz. It may be delayed or inaccurate.
